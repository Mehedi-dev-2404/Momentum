# Momentum
Momentum is a productivity system that helps students and professionals plan work around how they actually function, not just static deadlines. Instead of treating all tasks equally, Momentum combines deadlines, estimated effort, and daily energy levels to generate a realistic execution plan that reduces burnout and last-minute stress.  The system prioritizes tasks dynamically, adjusts plans when energy drops or deadlines change, and highlights high-impact work that should be done when focus is strongest. Built with clean object-oriented design, Momentum models tasks, deadlines, and energy profiles as first-class entities, making the logic extensible and testable.  Momentum solves a real problem most planners ignore: people don’t fail because they don’t know their deadlines they fail because they plan without accounting for energy and cognitive load.
